# JALA SQL Assignment Answers

Files:
1. `01_database_setup.sql` - creates database, tables, and inserts sample data.
2. `02_all_89_query_answers.sql` - contains all 89 MySQL query answers.

How to run:
1. Open MySQL Workbench.
2. Open and execute `01_database_setup.sql`.
3. Open `02_all_89_query_answers.sql`.
4. Run each query one by one.

